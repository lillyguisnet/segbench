The reference

How points match

Each reference dot gets a radius equal to 10%, 25% or 50% of the distance to its nearest reference neighbour, capped at 2% of the photo diagonal.

We find the largest one-to-one matching: duplicates and extra dots lose precision; missed objects lose recall. Dishes also need the correct dirty/clean label.

Quality is the average F1 over the three tolerances, with each task weighted equally. Click any table row to inspect its dots below.

Limitations and next steps
  • A correctly placed point far from your reference dot can fail; a nearby background point can pass. Object masks will replace this distance proxy later.
  • Reference points were corrected from model proposals. Shared model omissions and human anchoring are still possible.
  • No per-answer coordinate swapping or format repair. Malformed replies score zero; their object counts are unknown, not zero.
  • Only finder calls count here. SAM 1/2 outline pipelines, red foliage and roads do not enter this point-only round.
  • Language-model latency is one observed call per task; no confidence interval or universal winner can be inferred.
  • RF-DETR only attempted cows. A partial task mean would unfairly reward avoiding difficult tasks, so it is shown only by task.
